* ChopDat! A simple parsing library

  ChopDat is a work in progress parsing library. It currently supports only CSV
  (Comma Separated Values) parsing, but is soon going to support many other file
  formats.

** Parsing CSV files

  The library provides CSV parsing features through a recursive descent
  approach. The supported context-free grammar is a simplified version of the
  official CSV grammar from [[https://www.rfc-editor.org/rfc/rfc4180][RFC 4180]], written in [[https://en.wikipedia.org/wiki/Backus%E2%80%93Naur_form][BNF]] (Backus-Naur Form); in
  classic matemathical language:

  #+begin_latex

  $$
  \mathcal{G}=\begin{cases}
\Sigma=\{\texttt{\textbackslash r},\ \texttt{\textbackslash n},\ \texttt{,},\ \texttt{"}\}\ \cup\ \{\texttt{␣}..\texttt{!}\}\ \cup\ \{\texttt{\#}..\texttt{+}\}\ \cup\ \{\texttt{-}..\texttt{\textasciitilde}\}\\
\mathcal{V}=\{R,E,W\}\\
\mathcal{T}=\{C_R,\ L,\ C_F,\ C_M,\ D,\ T\}\\
\mathcal{P}= \begin{cases}
R\Rightarrow E\ C_M\ R \\
R\Rightarrow E\ C_F \\
R\Rightarrow \varepsilon \\
E\Rightarrow D\ W\ D \\
W\Rightarrow T\ W \\
W\Rightarrow T \\
C_R\Rightarrow \texttt{\textbackslash r} \\
L\Rightarrow \texttt{\textbackslash n} \\
C_F\Rightarrow C_R\ L \\
C_M\Rightarrow \texttt{,} \\
D\Rightarrow \texttt{"} \\
T\Rightarrow \{\texttt{␣}..\texttt{!}\} \\
T\Rightarrow \{\texttt{\#}..\texttt{+}\} \\
T\Rightarrow \{\texttt{-}..\texttt{\textasciitilde}\}
\end{cases} \\
\mathcal{S}=R
\end{cases}
  $$

  #+end_latex

  This simplified grammar assumes that:

  * a CSV file is a sequence of =records= (/including the empty sequence/),
  * a record is structured into =enclosed_fields= (/fields enclosed by double
    quotes/), separated by =COMMA= (s) and ending in a =CRLF= (/i.e. Carriage Return,
    Line Feed/),
  * an enclosed field is structured as a =word= enclosed in =DQUOTE= (s) (/double quotes/),
  * a =word= is a sequence of *at least* one unicode character, except from
    commas, double quotes and new lines.

  Imposing such limitations to the original grammar, thus to the language it
  generates, largely eases the complexity of our parser. Nonetheless, being this
  CSV "dialect" quite common, this parser allows real world usage.
